How to Run the Terminal CLI:

Open your command prompt or terminal in this folder and run:

python cli.py

Features interactive menus, ANSI formatting, defensive input loops, and Matplotlib chart exports.

How to Run the Python Web Server:

To run the local web server with full REST APIs:

python server.py

Starts an HTTP service on http://localhost:8000 serving the web UI and live endpoints.

Generate Matplotlib Visual Charts:

python generate_charts.py

Exports high-resolution multi-panel plots directly to campus_analytics_charts.png.
